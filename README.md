# ケイドロ プロトタイプ

ケイドロ（警察と泥棒）をゲーム化するにあたっての、要件検証用プロトタイプ。
プレイヤーは**警察**。制限時間3分以内に泥棒4人を全員収監できれば勝ち。

**▶ [ブラウザで遊ぶ](https://springace.github.io/keidoro/)**

## 操作

| | PC | スマホ |
|---|---|---|
| 移動 | WASD / 矢印キー | 画面左側をなぞる |
| ダッシュ | Shift | 「走る」ボタン |
| リスタート | R | 結果画面をタップ |
| 音の ON/OFF | M | 「♪ 音」ボタン |

音はブラウザの自動再生制限のため、**最初にキーを押すか画面に触れた時点**から鳴り始める。

## ルール

- マップは1画面固定で、3×3の9エリアに分かれている
- **自分がいるエリアの中しか見えない**。他の8エリアは暗いフォグに覆われる
- エリアの外に出た泥棒も、3秒間だけ赤い輪郭で位置が残る（マーク）
- 泥棒に触れると南東の牢屋へ収監
- 泥棒の頭上の記号は状態表示。`!` = 全力逃走中、`?` = こちらの気配に気づいて距離を取っている

## 迷路のギミック

**すべて警察・仲間・泥棒に等しく効く。**追う側の武器であると同時に、逃げる側の武器でもある。

| ギミック | 数 | 挙動 |
|---|---|---|
| **開閉扉** | 4枚 | 5.0秒開き→3.2秒閉じるを繰り返す。閉まる1.0秒前から橙色に点滅して予告する |
| **ワープ** | 3箇所 | 紫の渦。踏むと**別のワープ先へランダムに転送**される。再使用は2.5秒待ち |
| **針の床** | 3組 | 2.8秒引っ込む→0.7秒予告→1.5秒突き出す。刺さると2.5秒間、移動速度が半分になる |

扉はそれぞれ位相をずらしてあるので、同時に閉じるのは最大2枚。針も組ごとに位相が違う。

### 設計上の制約

**閉じた扉がマップを分断してはならない。**分断すると迂回路が消えてプレイヤーが詰み、
AIも経路を失って停止する。そのため扉の位置は「4枚すべてを同時に閉じても全床マスが連結」で
あることを確認して選んである。この保証があるので、**AIの経路探索は閉じた扉を壁として扱える**
（必ず迂回路が見つかる）。扉の前で立ち往生せず、回り込んでくる。

扉が閉じた瞬間にその中にいた場合は、**出るのは自由・入るのは不可**という扱いにして、
閉じ込められないようにしてある。

## 味方AI警官

**位置はフォグを無視して常に見える。**そのため、その状態がそのまま索敵の手がかりになる。

| 表示 | 状態 | 意味 |
|---|---|---|
| 青「仲間」 | 平時 | 巡回中。そのエリアに泥棒はいない |
| 橙「警戒」＋エリアが琥珀色に点滅 | 警戒 | **泥棒を発見して追っている。今すぐ向かえ** |

**収監できるのはプレイヤーだけ。**仲間は泥棒に追いつくと4秒間その場に足止めする（頭上に「確保」と出て、
フォグ越しでも見える）。この間に駆けつければ収監できるが、逃せば足止めは解ける。
恒久的に泥棒を無力化する手段は存在しない。

## サウンド

**音声ファイルは一切使わず、Web Audio ですべて合成している。**BGMは固定の曲ではなく、
盤面の状況に追従して鳴り方が変わる。

| 状況 | 曲 |
|---|---|
| 何も見えていない | 低音の脈打ちとキックだけ。静か |
| 仲間が警戒中 | ハイハットが入り、テンポが少し上がる |
| **泥棒を視認中** | 高音の短2度がぶつかる音形と増4度のパッドが乗る。最も速い |

さらに**残り時間が減るほどテンポが上がり**（126→160 BPM）、残り約50秒からは裏拍に時計の刻みが入る。
残り60秒と30秒で警告音、残り10秒からは毎秒の秒読みが鳴る。

効果音は、視認・収監・仲間の警戒・足止め・息切れ・ワープ・針・扉の開閉・勝敗の12種類。

## 設計のねらい

**素の足は警察が速く、ダッシュ中だけ泥棒が速い。**
そのため一度見つければ長期的には必ず追いつくが、短期的には振り切られる。決着はスタミナがつける。

泥棒は距離に応じて3つの状態を取る。距離はプレイヤーと味方警官の**近いほう**で判定する。

| 距離 | 状態 | 挙動 |
|---|---|---|
| 遠い | 徘徊 | 追手のいるエリアを避けて歩き回る |
| 16マス以内 | 回避 | 気配を感じて距離を取る（歩き） |
| 7マス以内 | 逃走 | 全力で逃げる（ダッシュ） |
